# 自动分类规则与蒸馏规范

本文件是 `douyin-group-video-distiller` 的阶段 4、5 依据。判定输入按权重排序：**转录内容（50%）> 视频标题/话题（30%）> 群内附带文字（20%）**。

## 分类体系

| 类别 | 定义 | 典型特征 |
|---|---|---|
| 技术干货 | 教学、讲解、实操教程、原理剖析、经验分享 | 口播式讲解、演示操作、步骤化内容、"教你/如何/原理/避坑" |
| 开源GitHub | 项目、代码、仓库、工具库、开发者生态内容 | 出现 GitHub、仓库名、star、PR/Issue、API、代码截图、开源协议 |
| 行业资讯 | 新闻、动态、政策、数据报告、事件报道 | 时效性强、"发布/宣布/最新/报告/融资/监管" |
| 对标案例 | 账号、博主、玩法、变现、商业案例拆解 | 账号名、粉丝量、GMV、投流、带货、爆款拆解 |
| 观点认知 | 观点输出、方法论、思维模型、价值判断 | 第一人称论述、总结性断言、"我认为/本质是/方法论" |
| 其他 | 无法归入以上类别，或内容无有效语音 | 闲聊、无内容、信号冲突且无法裁定 |

## 判定矩阵（按强信号优先）

命中任一强信号词 → 直接判定该类别，不再看内容特征：

| 类别 | 强信号词 |
|---|---|
| 技术干货 | 教程、干货、实操、原理、避坑、保姆级、手把手、代码讲解、架构、算法、Prompt工程、Agent、RAG、微调、工作流 |
| 开源GitHub | GitHub、Github、仓库、repo、开源项目、star、PR、commit、API、SDK、框架名+项目（如 LangChain、AutoGPT、Coze 开源）、huggingface |
| 行业资讯 | 发布、官宣、最新、首发、融资、监管、政策、报告、白皮书、增长数据、财报 |
| 对标案例 | 账号拆解、涨粉、GMV、投流、ROI、带货、爆款、人设、对标、起号、变现模式、佣金 |
| 观点认知 | 我认为、本质、底层逻辑、认知、方法论、思维方式、长期主义、复盘（总结性） |

无强信号时按内容特征裁定（转录中高频出现的行为模式）：

- 主体是"讲怎么做的过程/步骤" → 技术干货
- 主体是"某个项目/工具本身" → 开源GitHub
- 主体是"某个新发生的事/数据" → 行业资讯
- 主体是"某个账号/商家怎么做成的" → 对标案例
- 主体是"一个道理/观点的论证" → 观点认知

## 裁定优先级（信号冲突时）

1. 同时命中多个强信号 → 按「技术干货 > 开源GitHub > 行业资讯 > 对标案例 > 观点认知」取最先命中且内容主体吻合者。
2. 举例说明：讲"用 GitHub 上的 Agent 框架做短视频脚本" → 主类别 技术干货，标签 [GitHub, 内容创作]；讲"某工具在 GitHub 上 star 涨了 5 倍" → 行业资讯（事件），标签 [GitHub]。
3. 每条视频只记 1 个主类别 + 最多 2 个标签。

## 蒸馏产物模板

对每个类别，按以下结构产出（每类视频数量 ≥3 时，在归档文档中该类增加"共性总结"一节）：

### 核心资产（必填节，逐项留存，禁止丢弃）
- **核心图片**：视频关键画面（标题卡、提示词画面、安装/运行结果、图文封面、成果展示）。动作：对视频抽帧（建议标题处 0-2s、信息密集处 5-15s，图文帖直接用封面原图）→ 下载/裁剪 → 归档到 `<归档根>/assets/<作者>_<内容描述>.jpg` → 卡片中列出文件路径。若视频为纯音频/无画面流（可用 ffprobe 确认无 Video 流），写"无（纯音频流）"并注明核实方式。
- **提示词**：视频画面/描述中出现的提示词、操作指令全文 → 从关键帧 OCR 提取后原样入卡，标注"画面 OCR 提取，遮挡处按回复推断"；作者未公开的（如"评论区索取"）写"视频中未展示，待获取"。
- **项目地址**：视频中出现的 GitHub 仓库 / 项目 / 工具地址 → 入卡并联网核实补全（作者仓库、官方发布仓库、官方文档页分开列）；无则写"无"。

### 一句话结论
> 这条视频的核心价值：<一句话，聚焦"对你有什么用">。

### 核心要点
- 要点1（≤30字，可执行优先）
- 要点2
- 要点3

### 可执行清单
- [ ] 可以直接做的事1（如无，写"无直接动作，属认知积累"）

### 关联提示
- 关联已有归档/主题/可复用的 Skill（如"与上周 GitHub 蒸馏内容同主题"）；无关联写"无"。

### 各类别一句话结论的侧重
- 技术干货：这条视频教你/演示了什么，能不能直接复用。
- 开源GitHub：这个项目解决什么问题、值不值得试、怎么接入。
- 行业资讯：这条动态对你的业务/技能方向意味着什么。
- 对标案例：这个案例的打法是什么、哪些可借鉴。
- 观点认知：这个观点是否成立、对你决策有什么影响。
